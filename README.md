# 운용데스크 설치·운영 안내

폰·패드에 앱처럼 설치해서 쓰는 투자 운용 도구입니다. 종가·수급 기반 매력도 TOP10, 포트폴리오와 리스크, 금리·환율·물가, 투자 아이디어, 일정을 한곳에서 관리합니다.

## 폴더 구성
- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` : 앱 본체 (그대로 웹에 올리면 됩니다)
- `data/` : 자동 갱신 데이터가 들어가는 곳 (`market.csv`, `macro.json`)
- `pipeline/update_data.py` : KRX 종가·수급과 금리·환율·물가를 받아 `data/`를 만드는 스크립트
- `.github/workflows/update-data.yml` : 평일 장 마감 후 스크립트를 자동 실행하는 설정

## 1. 가장 빠른 설치 (약 5분)
1. 브라우저에서 https://app.netlify.com/drop 을 엽니다.
2. 이 폴더 전체를 화면에 끌어다 놓습니다. 주소(https://…netlify.app)가 만들어집니다.
3. 폰·패드에서 그 주소를 엽니다.
   - iPhone·iPad: Safari에서 공유 버튼 → "홈 화면에 추가"
   - 안드로이드: Chrome 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"

주의: 반드시 https 주소여야 설치와 오프라인 기능이 동작합니다. 파일을 그냥 열어서는 설치되지 않습니다.

## 2. 매일 자동으로 데이터 받기 (GitHub)
1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다. `.github` 폴더도 꼭 포함하세요.
2. 저장소 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 지정합니다. 앱 주소가 만들어집니다.
3. 한국 금리·물가까지 보려면 한국은행 ECOS 인증키(https://ecos.bok.or.kr, 무료)를 받아 저장소 Settings → Secrets and variables → Actions에 `ECOS_KEY`로 등록합니다. 없어도 시장 데이터, 환율, 미국 지표는 동작합니다.
4. Actions 탭 → `update-data` → Run workflow로 처음 한 번 실행합니다. 이후 평일 18:30(한국시간)에 자동 실행되어 `data/`가 갱신됩니다.
5. 앱을 열면 `data/market.csv`, `data/macro.json`을 자동으로 읽습니다. 설정 화면에 "자동 갱신 파일에서 불러왔습니다"가 보이면 연결된 것입니다.

저장소가 공개이면 앱 주소와 시장 데이터(공개 시세)도 공개됩니다. 거래 기록·아이디어·일정은 저장소에 올라가지 않고 각자 기기에만 저장됩니다.

## 3. 내 기록 보관
- 거래 기록, 아이디어, 일정은 기기의 브라우저 저장소에 저장됩니다. 폰과 패드 사이에 자동으로 동기화되지는 않습니다.
- 설정 → 백업/복원에서 백업 데이터를 복사해 다른 기기에서 복원할 수 있습니다. 정기적으로 백업해 두세요.
- 브라우저 데이터 삭제나 앱 삭제 시 기록이 사라질 수 있습니다.

## 4. 직접 CSV로 넣기
설정 → CSV 가져오기. 종목·일자별 한 줄씩 담습니다.
```
일자,종목코드,종목명,시장,업종,종가,거래량,외국인순매수,기관순매수
20261120,005930,삼성전자,KOSPI,반도체,71200,12345678,15200000000,-3100000000
```
필수는 일자·종목코드·종가·거래량입니다. 종목당 최소 71거래일이 필요합니다. 순매수 단위(원/억원)는 가져올 때 선택합니다.

## 5. 산식 요약
- 매력도(0~100): 추세 30 · 수급 30 · 모멘텀 20 · 거래량 10 · 안정성 10 가중 평균. 가중치는 설정에서 바꿉니다.
  - 추세: 20일선·60일선 위치, 정배열, 60일선 기울기
  - 수급: 외국인+기관 5일·20일 순매수를 거래대금으로 나눈 값, 연속 순매수 일수
  - 모멘텀: RSI(14), MACD 히스토그램, 20일 수익률
  - 안정성: 20일 변동성, 120일 고점 대비 낙폭, 20일선 이격 과열
- 포트 리스크: 현재 비중을 최근 120거래일에 적용한 역사적 시뮬레이션(변동성, 95% VaR, 최대낙폭, 시장 대비 베타, 평균 상관, 위험 기여도).
- 아이디어 사이징: 켈리 공식 f* = p − (1−p)/b 의 ¼, 1% 리스크 룰(1% ÷ 손절폭), 종목 한도 중 최솟값.
- 매크로 레짐: 환율 변화, 장기금리 변화, 한미 금리차, 장단기 스프레드, 물가, 실질금리 6개 요인을 규칙으로 점수화.

## 6. 한계와 검증 현황
- 점수 가중치와 기준값은 일반적인 시장 관행에 근거한 초기값이며 백테스트를 거치지 않았습니다. 자체 데이터로 검증한 뒤 조정하세요.
- 계산 로직은 단위 테스트(과거 데이터만 사용하는지, 포지션·손익·켈리·위험기여 합계 등)로 확인했습니다.
- `update_data.py`는 가짜 데이터 소스로 출력 형식과 앱 호환성만 검증했고, 실제 KRX·ECOS·FRED 서버에는 호출해 보지 못했습니다. KRX는 로그인 정책이 바뀔 수 있으니 처음 실행 때 Actions 로그를 확인하고, 오류가 나면 로그를 알려 주세요.
- 이 도구의 결과는 참고 자료이며 투자 권유가 아닙니다. 투자 판단과 책임은 본인에게 있습니다.
